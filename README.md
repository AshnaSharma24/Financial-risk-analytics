## 🚀 Overview

The Financial Portfolio Risk & Analytics Engine is an interactive financial analytics platform that helps investors evaluate portfolio performance using real-time market data.

The application provides advanced risk analysis, portfolio performance metrics, diversification insights, and interactive visualizations to support informed investment decisions.

---

## ✨ Key Features

✅ Real-time stock data retrieval using Yahoo Finance

✅ Intelligent ticker validation with automatic fallback support (e.g., Indian stocks `.NS`)

✅ Portfolio return calculation

✅ Portfolio volatility analysis

✅ Sharpe Ratio for risk-adjusted performance measurement

✅ Value at Risk (VaR) estimation for downside risk assessment

✅ Correlation analysis for diversification evaluation

✅ Interactive correlation heatmaps

✅ Interactive cumulative return visualization

✅ Adjustable rolling volatility analysis with user-defined window size

✅ Portfolio allocation visualization

✅ Automatic portfolio weight normalization

✅ Interactive Plotly-powered dashboards

✅ Robust error handling and data validation

## 📊 Analytics & Risk Metrics

### ✔ Expected Portfolio Return

Calculates the weighted average return generated by the portfolio.

### ✔ Portfolio Volatility

Measures portfolio risk using covariance and standard deviation calculations.

### ✔ Sharpe Ratio

Evaluates portfolio performance relative to the amount of risk taken.

### ✔ Value at Risk (VaR)

Estimates the maximum expected loss within a specified confidence interval.

### ✔ Correlation Analysis

Identifies relationships between assets to assess diversification benefits.

### ✔ Rolling Volatility

Tracks changes in portfolio risk over time using customizable rolling windows.

### ✔ Cumulative Returns

Visualizes long-term portfolio growth and performance trends.

## ⚙️ How It Works

1. User enters stock tickers and portfolio weights
2. Application validates ticker symbols
3. Historical market data is fetched from Yahoo Finance
4. Portfolio returns are calculated
5. Risk metrics are computed
6. Interactive visualizations are generated
7. Portfolio insights are displayed through an analytics dashboard
